# Kernel Consumption

> Interlock consumes SDE's kernel physics for runtime configuration

## Overview

Interlock loads physics values from `kernel/hardware_profile.json` (generated by SDE's `ship` command) and uses them to configure circuit breaker thresholds, recovery intervals, and confidence gates.

---

## Environment Variable

```bash
# Override kernel path
export COGNITIVE_KERNEL_PATH=/path/to/hardware_profile.json

# Default locations (in order):
# 1. ./kernel/hardware_profile.json
# 2. ../Simulated-Desire-Engine/kernel/hardware_profile.json
# 3. ~/.cognitive-kernel/hardware_profile.json
```

## Kernel Schema (v0.2.0)

```json
{
  "schema_version": "0.2.0",
  "source": {
    "domain": "ollama",
    "packet_id": "ep_battery_ollama_20251216_015924",
    "quality_level": "L2-StressBattery",
    "law_hash": "abc123",
    "sde_commit": "0692692f"
  },
  "physics": {
    "max_safe_latency_ms": 1900,
    "min_confidence_floor": 0.5,
    "error_threshold_rate": 0.05,
    "recovery_timeout_ms": 60000,
    "probe_interval_ms": 15000
  },
  "status": {
    "mode": "PRODUCTION",
    "last_ship_at": "2025-12-16T..."
  }
}
```

---

## Physics → Config Mapping

| Kernel Physics | Interlock Config | Notes |
|---------------|-----------------|-------|
| `max_safe_latency_ms` | `latencyThresholdMs` | Circuit breaker threshold |
| `min_confidence_floor` | `minimumConfidenceThreshold` | Confidence gate |
| `error_threshold_rate` | `hazardThreshold` | Inverted: `1 - rate` |
| `recovery_timeout_ms` | `minimumOpenDurationMs` | Recovery cooldown |
| `probe_interval_ms` | `recoveryCheckIntervalS` | Divided by 1000 |

---

## Safety Bounds

Values are clamped to prevent misconfiguration:

| Field | Min | Max |
|-------|-----|-----|
| `latencyThresholdMs` | 1ms | 120,000ms |
| `error_threshold_rate` | 0 | 1 |
| `probe_interval_ms` | 100ms | 300,000ms |
| `recovery_timeout_ms` | 0 | 3,600,000ms |
| `confidence_floor` | 0 | 1 |

## Event Stamping

All emitted events include kernel provenance:

```json
{
  "event_type": "health_window",
  "timestamp": "2025-12-16T...",
  "domain": "ollama",
  "kernel": {
    "schema_version": "0.2.0",
    "packet_id": "ep_battery_...",
    "law_hash": "abc123",
    "quality_level": "L2-StressBattery",
    "domain": "ollama"
  }
}
```

If kernel is missing:
```json
"kernel": {
  "schema_version": "unknown",
  "law_hash": "default",
  "missing": true
}
```

---

## Boot Event

At startup, Interlock emits a `kernel_boot` event:

```json
{
  "event_type": "kernel_boot",
  "timestamp": "2025-12-16T...",
  "kernel": { ... },
  "effective_config": {
    "latencyThresholdMs": 1900,
    "hazardThreshold": 0.95,
    ...
  },
  "loaded_from": "./kernel/hardware_profile.json",
  "warnings": []
}
```

## Integration Example

```typescript
import { 
    loadKernel, 
    applyKernel, 
    initKernelStamp,
    createKernelBootEvent,
    stampEvent 
} from './services/kernel';

// At boot
const kernelResult = loadKernel();
const config = applyKernel(kernelResult.physics);
initKernelStamp();

// Log boot event
const bootEvent = createKernelBootEvent(config);
emitEvent(bootEvent);

// During operation - stamp all events
const healthEvent = { event_type: 'health_window', ... };
const stampedEvent = stampEvent(healthEvent);
emitEvent(stampedEvent);
```
